# EcoCycle — Revisão React 1 e 2 (ESQUELETO)

Projeto já criado, com o CSS pronto. Você completa o código tópico a tópico.

## Como começar
```bash
npm install
npm run dev
```
Abra o endereço que aparecer (http://localhost:5173).

## Como fazer
1. Siga o **Guia de Live Coding** na ordem: T1, T2, T3...
2. No VS Code, aperte **Ctrl + Shift + F** e procure `TODO T2` (depois `TODO T3`...).
3. Faça o que o TODO pede, **salve** e confira o resultado no navegador antes de ir para o próximo.
4. Quando terminar um TODO, pode apagar o comentário.

Arquivos que você vai mexer: `src/App.jsx`, `src/components/Header.jsx`, `src/components/Rodape.jsx`,
`src/components/CardMaterial.jsx` e `src/data/materiais.js`.
