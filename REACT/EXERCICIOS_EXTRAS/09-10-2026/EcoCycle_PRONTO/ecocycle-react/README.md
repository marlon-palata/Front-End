# EcoCycle — Revisão React 1 e 2 (PROJETO PRONTO)

Projeto completo da revisão das Aulas 3 e 4 (React 1 e React 2).
Comentários `// T1` a `// T12` mostram de qual tópico veio cada parte.

## Como rodar
```bash
npm install
npm run dev
```

## Tópicos
| Tópico | Assunto | Aula |
|---|---|---|
| T1 | Criar e rodar o projeto (terminal) | React 1 |
| T2 | JSX: className, JavaScript entre { }, comentário | React 1 |
| T3 | Componentes Header e Rodape (export default / import) | React 1 |
| T4 | Props | React 1 |
| T5 | Lista + `.map()` + key | React 1 |
| T6 | `toLocaleString` (R$), `.length`, ternário | React 1 |
| T7 | Dados em `src/data` (export nomeado) | React 2 |
| T8 | `onClick` com variável comum (a tela não muda) | React 2 |
| T9 | `useState` (a tela muda) | React 2 |
| T10 | `!` e `&&`: mostrar / esconder a dica | React 2 |
| T11 | Função como prop: total no Header | React 2 |
| T12 | Desafio: zerar a coleta | React 2 |
